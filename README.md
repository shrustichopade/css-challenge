
# CSS Challenge

## Project Overview
A practical CSS project created for WeIntern Week 1 Task 3.

## Objective
Practice Flexbox layouts, responsive CSS Grid, and subtle CSS animations.

## Technologies
- HTML5
- CSS3
- JavaScript

## Features
- Three responsive Flexbox feature cards
- Six CSS Grid gallery items
- Responsive desktop, tablet, and mobile layouts
- Card hover and lift effects
- Animated button and loading spinner
- Responsive typography and spacing
- Reduced-motion accessibility support

1. Open the folder in VS Code.
2. Open index.html using Live Server.
3. Resize the browser to test responsive behavior.
